# Homebrew Tap for OpsLens

Install OpsLens on macOS or Linux:

```bash
brew install niuguy/tap/opslens
```

The formula is generated from the architecture-specific archives and SHA-256
checksums in the latest public
[OpsLens release](https://github.com/niuguy/opslens/releases/latest).

This is the upstream-maintained third-party tap. It is not part of
`homebrew/core` and does not imply endorsement by the Homebrew project.
